   Loading the full library
   This tab says what goes on the box for each game, where it comes from, and how to load
   it. The other tabs teach the games in the box's own words. This one is about putting the
   actual rules text, cards and your own books on the box so it can look things up.



   The short version
          Officially free material loads in full. That covers more than it used to: the 40k core
          rules and every faction pack, every kill team's rules, the D&D rules document (SRD
          5.2.1), every Magic card, and Magic's complete rulebook.
          Paid books load from your own copies. Codexes, the Kill Team core book, D&D
          rulebooks and campaign books go in a folder called mine . The box indexes them page
          by page and answers with the book name and page number.
          I can't supply the text of paid books. They are copyrighted, so none of it is in this
          document or in the loader. The loader only reads files you give it.

   Two limits worth knowing:

          The 40k app and D&D Beyond do not export files. A codex code unlocks the codex
          inside the official app only. Books you own there or on paper need your own digital
          copy or your own scan before the box can index them. Whether to scan a book you
          own is your decision.
          The Munitorum Field Manual is now a web page, not a PDF. Open it in a browser and
          use Print, then Save as PDF, and drop that file in the free/wh40k folder.

   The file name becomes the book name the box says out loud, so name files the way you
   want them read: Players Handbook.pdf , not phb_final_v2.pdf .

   Anything inside a folder called campaigns is DM only. Player lookups never show it, and
   the box only uses it in DM mode.


   Loading it
   Do this on a PC, then copy content.db to the Pi. It also runs on the Pi, only slower.

      1. Install the one extra piece the loader needs: pip install pypdf
      2. Index every file in free and mine : python3 dt_content.py sync content
      3. Download and load every Magic card: python3 dt_content.py fetch-mtg content
      4. Load the Magic rulebook: python3 dt_content.py mtg-rules
          content/free/mtg/MagicCompRules.txt
      5. Check what went in: python3 dt_content.py stats

   Run step 2 again whenever you add, replace or delete a file. It only re-reads files that
   changed.

   Try it from the command line before it goes on the box:

            python3 dt_content.py search "restrained" --game dnd

            python3 dt_content.py card "llanowar"
            python3 dt_content.py search "room 14" --game dnd --dm

   What the loader reads

     File type             How it is split                   What the box quotes

     PDF                   One entry per page                Book name and page number

     EPUB                  One entry per chapter             Book name and chapter number

     Markdown              One entry per heading             Book name and heading

     Plain text            Parts of about 3,500 characters   Book name and part number


   Things that will not load, and what the loader says:

          A scanned PDF with no text layer. The loader reports NO TEXT FOUND . Run the file
          through OCR first (the free tool ocrmypdf does this), then sync again.
          A copy-protected EPUB. The loader reports it and skips it. It does not try to remove
          the protection.
          Photos and other file types. Reported as not supported and skipped.


   How the box uses the library
          Lookup screens search the library directly. No internet needed.
          Spoken questions work like this: the box finds the three best-matching entries, sends
          them with your question to the cloud model, and shows an answer that names the
          book and page. This means short excerpts of your own books leave the box when you
          ask a question. Campaign books are only ever sent in DM mode.
          Magic card lookups show the card's current official wording, legal formats and
          rulings. The screen credits Scryfall.
          D&D answers from the SRD carry the credit line the licence asks for: material from
          SRD 5.2.1 by Wizards of the Coast LLC, used under CC BY 4.0. The full credit sits in
          Settings, About.

          including a PDF with a blank page in the middle.

          A changed file is re-indexed, a deleted file is removed, and an unchanged file is left
          alone.
          Campaign files are hidden from player search and visible in DM mode.

   Not tested: the real downloads. My workspace could not reach Scryfall, Wizards or
   Warhammer Community, so every test used small made-up files in the same layout as the
   real ones. Expect one round of fixes after your first real run. The likeliest trouble spots:

          Two-column rulebook PDFs sometimes come out with the columns interleaved.
          Search still works, but excerpts may read oddly.
          Datasheet tables in faction packs may lose their column alignment.
          The fetch-mtg download has never run against the live Scryfall service.

   Send me the output of stats and one or two odd-looking search results and I will fix the
